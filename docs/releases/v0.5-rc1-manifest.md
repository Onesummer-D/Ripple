## 运行、安全与回滚

- 推荐环境：Node 22、`npm ci`、Linux Docker/Chromium CI；Windows 本地 Docker 不可用时以 Linux CI 为权威。
- 真实 API 保持 loopback 访问；不得直接暴露到公网。
- Candidate 级回滚：服务端 `POST /candidate/rollback`，只接受当前已应用且仍可回滚的 Candidate。
- 版本级回滚：发布系统应回退到已验收的 #64 HEAD `0a301b04f73d08d972c971571fcd74fe5ddfb4cf`，不得把旧公网 Demo 当作 RC1 回滚目标。
