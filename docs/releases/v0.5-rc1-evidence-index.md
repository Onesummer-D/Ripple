## 安全负例

- stale DOM、query/hash 变化、HashRouter、React.memo 旧 DOM：保持 `route-namespace-stale` 和 fail-closed。
- duplicate、missing、错误叶子、祖先伪造、版本变化、digest mismatch：不产生实例证明。
- archive failed、无 Web Crypto、缺失配对记录：诊断可见且不升级为 PASS。
- CSS Token 动态 className、未解析 cascade、UNKNOWN consumer：保持 `semantic-candidate / unknown`，不改变授权。
