## 改进 1：动态路由 / SPA 状态切换工程的验证合同支持

**现状**：A 核心的验证合同要求合同页面路径为同源根绝对路径（`/` 开头），且合同页面集合必须与工程全部路由一致。SPA 状态切换页（路由路径非根绝对路径，如 `home`、`/product/:id` 动态段）无法提交合同 → interaction / scope-propagation 断言保持 unknown（fail-closed）。这是已证明的安全门控，**不回退**。

**用户影响**：此类工程无法达到 7/7 passed，审批门控不可用，只能完成到候选与部分验证。

**改进方向（候选，需 A/C+D 合同层面先行）**：
1. 路由路径规范化：为无 leading slash 的声明式路由提供同源绝对路径推导规则（需 C+D 来源证明，不允许臆造）。
2. 动态段合同：允许合同页面以路由 id + 参数化路径声明，验证运行器按静态参数集展开（需 A 运行器支持）。
3. 部分合同显式声明：用户显式选择「仅这些页面参与合同」时，未覆盖页面对应断言如实保持 unknown 但允许其余断言出结论（当前 A 语义是合同页面必须与路由集合一致，改动属 A 核心合同，须 A 立项）。

**依赖**：A 核心 verify 合同语义、C+D 路由来源证明。**F 侧仅消费合同，不自行实现平行 SourceGraph。**

## 改进 2：移动端画布可读性（承接 10-23 UI 优化意见）

**现状**：1440 桌面画布缩放到手机宽度后内部文字过小。
