## 通用录屏设置（三类素材共用）

| 项 | 要求 |
| --- | --- |
| 屏幕/窗口 | 显示器 1920×1080；浏览器窗口最大化（内容区约 1920×940）；系统缩放 100% |
| 浏览器 | 干净的 Chrome/Edge profile 或访客窗口；缩放 100%；关闭书签栏与扩展图标 |
| 必须隐藏 | GitHub 头像/用户名/邮箱、浏览器通知、其他标签页标题、文件路径中的 Windows 用户名（工程统一放中性路径，如 `D:\ripple-rec\`） |
| 命名 | `rec-<120s|full>-s<镜号>-<内容>.mp4`，如 `rec-120s-s2-pick.mp4`；静态图 `shot-<镜号>-<内容>.png` |
| 每镜完成判据 | 画面 1080p 无个人信息；来源角标（REAL/DEMO/FIXTURE/CONCEPT）全程可见未被遮挡；操作一遍成功无回退废帧；文件名与镜头表对应 |

## A. F DEMO 演示界面（Windows 本地，最简单，最先录）

**用途**：120 s 镜 3/4；完整版镜 7。

1. **取代码（ZIP 方式）**：浏览器打开 <https://github.com/Onesummer-D/Ripple/archive/refs/heads/feat/project-first-core-20261018.zip> 下载并解压（git clone 443 失败时的标准替代；该分支已含 F 体验工作台）。
2. **启动**：目录内 `npm install`（或 `npm ci`，存在 lock 文件时）→ `npm run dev` → 浏览器打开 **http://localhost:4173/experience.html**（Vite 固定 127.0.0.1:4173）。
3. **确认标识**：页面顶栏应有 DEMO/SIMULATED 常驻标识；若进入任何 real 模式入口，退出——只录演示入口。
4. **录哪些真实可见界面**：
   - 关系涟漪图展开（reads 边点亮、三页高亮、独立页保持灰）→ 120 s 镜 3；
   - 范围决策 include/exclude 切换 → 门控拒绝 unknown 页面 → 120 s 镜 4；
   - 审批按钮与版本胶片界面扫过（文案原样，不点真实审批）→ 完整版镜 7。
5. **完成判据**：DEMO 角标全程可见；每镜至少 2 条可用素材；画面无个人信息。

6. **无法本地运行时的替代**：镜 3/5/6/8/9 直接用 `evidence/run18/` 归档截图做证据动画（B 类已就绪），成片不依赖本段录制。

**完成判据**：分析结果与归档 analysis.png 一致（4 页面）；点选返回 jsx:src/components/Footer.tsx 来源；录屏中工程路径无个人信息（用 `D:\ripple-rec\` 中性路径）。

## 推荐录屏顺序

1. **C 类先出粗剪**（素材已就绪，可立即开始）；
2. **A 类 F DEMO**（启动最简单，约 1 小时含环境）；
3. **B 类 A 工作台**（等负责人提供青野私有仓 ZIP）；
4. 可选补采 C-α/β/γ（B 类环境可用后）；
5. 合版 → 角标与个人信息终检 → 定稿。
